<div align="left">
  <h2><samp style="color: #00987a;">> system_features...</samp></h2>
</div>
<ul style="color: #c8c2b8;">
  <li><samp><b>Bespoke Aesthetics:</b> Powered by the custom <i>"ζωι"</i> (Zoi) color palette. Deep `#0f1714` backgrounds with high-contrast `#00987a` (Cyan) and `#f66e16` (Orange) accents.</samp></li>
  <li><samp><b>Advanced Hyprland Animations:</b> Custom Bezier curves (<i>softOut, silk, glide</i>) for buttery smooth window management and workspace transitions.</samp></li>
  <li><samp><b>Vim-like Workflow:</b> Fully integrated `H J K L` bindings for moving focus, moving windows, and resizing on the fly.</samp></li>
  <li><samp><b>Script-Heavy Waybar:</b> Minimalist top bar driven by custom bash scripts monitoring Intel iGPU, Nvidia dGPU, and Samsung NVMe states.</samp></li>
  <li><samp><b>Unified Theming:</b> Includes custom Sublime Text 4 themes (`Darkness` and `ζωι`) to perfectly match the OS environment.</samp></li>
</ul>
